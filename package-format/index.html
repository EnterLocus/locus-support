Locus Room package format

This reference includes the Room transport envelope, authorable Package-v2 fields, schemas, reproducible examples, packer, and validator.

Import paths. Import a View from one 2:1 JPEG, PNG, or HEIC image. A normal Room archive contains one Room; import its View separately.

Supported Room examples

The Demo Room uses the same Room design as the first Room included with Locus, Atrium Loft. It is an import-ready Room-only package example, not an additional Room design.

The example builder also produces combined and View-only archives for advanced format validation. They are not needed for normal Room authoring.

Using the sample skill

The Room-building skill is an optional example for AI-assisted authoring through Blender MCP. It guides modeling, packaging, and final entry checks. The validator checks the finished file but does not judge Room scale, comfort, or visual quality.
