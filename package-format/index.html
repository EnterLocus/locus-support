Technical reference

Locus Room and View ZIP format

One ZIP contains one Room or one View. Files stay at the ZIP root, and Locus assigns the asset UUID at import.

No authored IDs. Display names may repeat. Only the files listed below are accepted.

Room files

room.zip
├── space.json
├── provenance.json
├── teleport-points.json
├── scene.usdz
└── thumbnail.jpg

Every file is required. A Room must contain at least one usable entry seat. The thumbnail is supplied by the author; Locus does not capture one during import.

View files

view.zip
├── view.json
├── provenance.json
├── panorama.jpg
├── thumbnail.jpg
└── lighting.jpg       # optional

view.json can set direction, visible brightness, Room-lighting intensity, horizon pitch, contrast, saturation, and optional sunlight. The panorama is a complete 2:1 equirectangular image.
