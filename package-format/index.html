Reproducible examples

The examples contain generated 16 × 8 PNG data, a tiny structural USDZ, strict provenance, Package-v2 manifests, and canonical integrity fields. They contain no private room, paid provider output, account data, or proprietary launch media.

Authority and licensing boundary

The shipping Locus importer is the installation authority. The public validator is intended to catch authoring and CI failures before import, but a future app version can enforce additional compatibility or platform checks.

Publishing these documentation and tool files does not publish the private Locus app source, disclose its implementation, or state that the application has adopted an open-source license.
