# Concept and brief

Start with a written brief before opening a 3D tool. It keeps an attractive
concept image from becoming an unbuildable Room.

## Write the brief

Record the Room's purpose, mood, main activity, architectural type, important
materials, intended principal view, and the count and purpose of seats. State
which seats need a desk and which lamps a visitor can control. List the View
opening, likely wall and roof references, and any animation or sound as
optional scope. Keep a simple rights inventory for every supplied reference or
asset.

Define a compact acceptance list: no floating or intersecting objects, a clear
path and useful focal point from every seat, enough physical thickness for
surfaces that will be seen edge-on, and a safe, readable desk where one is
offered. This list is reviewed against renders and again on device.

## Choose a reference image

One approved reference image supplies the visual target and the camera target.
It may be a creator-supplied photo, a sketch, a quick Blender blockout render,
or output from any image model. Image generation is optional and no provider is
required. If an image model is used, record the material contribution in
provenance; a prompt alone does not prove authorship or redistribution rights.

Make a concept prompt specific about the camera as well as the place: eye
height, direction, focal length or field of view, foreground, room envelope,
day/night state, and the desired view through the opening. Avoid text, logos,
or tiny decorative features that a model cannot reproduce reliably. Prefer one
clear design basis over contradictory image references.

## Use the image through the build

Set a comparison camera to the reference's eye height, framing, and direction.
Render the first blockout from it. Compare silhouette, major openings, ceiling
height, horizon, desk position, and seat-to-focal-point relationship before
adding small objects. Repeat that comparison after materials and lights are
finished. The thumbnail uses the same visual promise, but it must show the
delivered Room rather than a concept image.

The reference guides design only. Review each actual seat separately after the
Room is built; a single attractive thumbnail cannot show a backwards chair,
an obstructed 360-degree surround, or insufficient overhead clearance.
