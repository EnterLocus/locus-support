# Locus support and documentation

This is the official public home for Locus support, feedback, documentation,
privacy information, launch copy, and the public Place-package authoring tools.
The site is published at <https://enterlocus.com/>.

The Locus application source is maintained in a separate private repository.
Making this support repository public does **not** publish the app source or
grant it an open-source license. No license for this repository is implied;
rights not expressly granted are reserved.

The repository includes an optional sample Room-authoring skill at
`.agents/skills/build-original-locus-room/SKILL.md`. The current package
reference and validator define the accepted Room file.

Use the Bug, Feature Request, or Wishlist form to post public feedback. Send
private or security-sensitive reports to support@enterlocus.com.
