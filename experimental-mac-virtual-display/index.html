Mac Virtual Display in an immersive scene

An optional, experimental Apple developer workflow. It is not required to use Locus, and Locus does not enable or control Mac Virtual Display.

Experimental · release verification pending
Not a guaranteed consumer feature. Availability and behavior are controlled by visionOS and can change. This workflow must be re-tested on the approved release build immediately before App Store submission.

Setup

  1. On Apple Vision Pro, open Settings → Privacy & Security → Developer Mode and enable Developer Mode.
  2. Restart Apple Vision Pro and confirm Developer Mode when visionOS asks.
  3. Open Settings → Developer.
  4. Enable Allow Mac Virtual Display.
  5. Start Apple's Mac Virtual Display normally.
  6. Return to Locus and enter a Virtual Space or Room Portal scene.

Developer Mode may first need to become available by pairing Apple Vision Pro with Xcode or establishing a development workflow.

Continue without Mac Virtual Display

Nothing in Locus depends on this setting. Leave Developer Mode or Allow Mac Virtual Display off and use Locus's own browser windows and Places normally.

Continue without Mac Virtual Display

What Locus does not do

  • No private API to enable or inspect Developer Mode.
  • No private API to enable, query, place, stream, or control Mac Virtual Display.
  • No undocumented Settings link or private preference probing.
  • No reverse engineering of Mac Virtual Display protocols.
  • No claim that the system Mac window is owned by Locus.

Troubleshooting boundaries

If the Developer section or switch is missing, first confirm the device's development pairing and the current visionOS documentation. If Mac Virtual Display closes or changes behavior when an immersive scene opens, exit the scene and continue using Locus without it. Do not install profiles, use private Settings links, or change undocumented preferences.

For a privacy-safe report, include the Locus build and visionOS version, whether Developer Mode and the switch were visible, and the sequence of system actions. Do not attach Mac screen content, notifications, room images, account data, or device identifiers to a public issue.

Current verification status

The setup steps above record the intended optional workflow from Locus's V1 plan. The publisher has not yet recorded a complete release-candidate device pass covering entry/exit, keyboard and pointer input, resizing, placement, and behavior with the setting disabled. This page deliberately does not claim that gate has passed.
