Optional setup

Use Mac Virtual Display in a Locus place

Mac Virtual Display normally doesn't work with immersive apps.

Requires Apple Vision Pro Developer Mode

How to enable it

To enable it, turn on Developer Mode — follow Apple's guide to pair your Apple Vision Pro with Xcode and enable Developer Mode — then turn on Allow Mac Virtual Display under Settings → Developer.

visionOS — not Locus — creates, places, streams, and controls the Mac window. Nothing in Locus depends on it; Locus's own browser windows and Places work normally without it.

Open Mac Virtual Display first

  1. Connect to your Mac with Mac Virtual Display from Control Center.
  2. Enter the Locus place.

If you open Mac Virtual Display after entering a Locus virtual environment, visionOS exits that environment. Reconnect to Mac Virtual Display first, then enter the Locus place again.
