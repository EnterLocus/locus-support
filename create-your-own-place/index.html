Authoring guide

Create a custom View or Room.

A View uses a complete panorama. A Room uses a validated ZIP containing one 3D Room.

Room and View ZIP format v1

Supported imports

ActionInputSource
Import a ViewA complete 2:1 equirectangular JPEG, PNG, or HEIC image; or one flat View ZIPPhotos, Files, or a direct public HTTPS URL
Import a RoomOne flat Room ZIPFiles or a direct public HTTPS URL

Import the View and Room separately. Locus assigns each imported asset a UUID. Names are display text and may repeat.

Try a complete Room

The Demo Room uses the same design as Atrium Loft, the first Room included with Locus. It is a complete import example, not a new Room design.

Download the ZIP, save it to Files, then choose Import a Room in Locus. It has two work seats and two desks and can be used with any compatible View in your library.

Use the sample Room skill

The public repository includes an optional sample skill for a compatible AI assistant. It uses Blender through Blender MCP and covers geometry, seats, the required thumbnail, packaging, validation, and entry checks.

The skill and validator do not create a finished Room by themselves or judge scale, comfort, and appearance. Import the result and try every seat.

Room ZIP layout

my-room.zip
├── space.json
├── provenance.json
├── teleport-points.json
├── scene.usdz
└── thumbnail.jpg

All five files are required and must be at the ZIP root. space.json contains displayName; it does not contain an asset ID. Do not add a parent folder, .blend, GLB, source textures, or any other file. Locus does not take a thumbnail when one is missing.

View ZIP layout

my-view.zip
├── view.json
├── provenance.json
├── panorama.jpg
├── thumbnail.jpg
└── lighting.jpg       # optional

The panorama must be a complete 2:1 equirectangular image. A packaged View can set starting direction, brightness, contrast, saturation, Room lighting, horizon pitch, and optional sunlight in view.json. A user can change these later with Edit View.

Adjust a View in Locus

Edit View provides View Brightness, Contrast, Color, Room Lighting, Add Sunlight, Sun Position, Sunlight Strength, and Turn the View. The settings are saved for that View.

Provenance

Every Room and View needs provenance.json. Record the creator or agency, asset license, requested credit, changes, and AI use truthfully. When aiGenerated is true, include aiProvider. The license describes rights in the asset; an App Store EULA is not an asset license. See Locus asset rights for Locus-authored examples.

Pack and validate

Keep the five Room files or four required View files in one directory. Run the included tools on macOS:

python3 tools/pack_locus_asset.py /absolute/path/to/asset /absolute/path/to/asset.zip
python3 tools/validate_locus_asset.py /absolute/path/to/asset.zip

The Room validator uses Xcode's usdchecker. A valid result checks the archive and machine-readable assets; it does not replace importing the exact ZIP and trying every seat.
