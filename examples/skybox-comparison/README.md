# One Maldives base, two enhancement routes

This demonstration freezes one original panorama and its exact generation
[prompt](prompt.txt), then compares Nano Banana Pro Batch with GPT Image 2.6
Sunburst. The accepted base is not regenerated, silently rotated or replaced
by a prior restored output. See [comparison.json](comparison.json) for hashes.

Current state: both agents completed free public-repository preflight;
**no model comparison output or actual paid cost is available yet**. First
restoration submissions require the creator's cost approval. The Nano Banana
credential reference is also pending. The source binary and future images are
kept outside Git; public download links will be added with the completed demo.

The completed comparison will show the following for each route:

| Stage | Evidence to publish | Current result |
| --- | --- | --- |
| Shared input | Original 1774×887 panorama, exact prompt, 360° preview and hash | Frozen; bytes identified in JSON |
| G restoration | Raw provider output, prepared input, unpadded output where applicable, sizes and usage | Pending |
| F detail | Six raw face outputs, actual sizes/FOV and representative native crops | Pending |
| Merge and repairs | Native-density panorama, merge receipt, repaired crops and original checkpoint | Pending |
| Final comparison | Same angular views, sky/shore/palm/nadir/wrap/face joins, dimensions, file size and actual cost | Pending |

Six faces cover the entire sphere for both models. The planned conservative
sampling sizes are roughly 7.3K wide for 2880-square GPT faces and 10.4K for
4096-square Nano Banana faces at 102° FOV. These are calculated expectations,
not generated results, measured resolved detail or quality acceptance. Final
export uses actual raw face sizes through the [public native-resolution rule](../../.agents/skills/build-a-view/references/resolution.md).

Do not compare screenshots scaled to different angular fields of view, label
an interpolated file native 12K, or omit rejected outputs/costs. The common
source itself has a wrap defect and different initial framing from its prompt;
that baseline is retained so the repair and preservation tradeoffs remain
visible. App import and physical headset appearance are separate checks.
