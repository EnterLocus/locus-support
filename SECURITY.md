# Private and security-sensitive reports

Do not open a public issue for a security concern or a report containing room
images, credentials, receipts, order details, account data, notifications,
device identifiers, or other personal information.

Email **support@enterlocus.com** with the subject `Locus private or security
report`. Include only the minimum detail needed to reproduce the problem. Do
not send passwords, recovery codes, payment-card data, or Apple ID credentials.

Public issue forms are for reports that can be shared safely.
