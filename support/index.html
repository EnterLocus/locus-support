Before reporting a problem

  1. Open Settings → About Locus and note the version, build number, and short build commit.
  2. Note the visionOS version without including an Apple ID, device serial number, or other identifier.
  3. Reduce the report to the smallest safe set of steps that reproduces the problem.
  4. Remove notifications, website account data, room details, receipts, and personal content from screenshots or recordings.

What support can and cannot verify remotely

Build and simulator evidence can help diagnose app state, navigation, layout, and package validation. Physical Apple Vision Pro behavior—tracking, passthrough, occlusion, comfort, presence, and perceived brightness—may require a device session and a privacy-safe description from the wearer.
